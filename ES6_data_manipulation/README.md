# JavaScript – ES6 Data Manipulation

## Description

Projet dédié à la manipulation de données en JavaScript avec les fonctionnalités modernes d’ES6, en mettant l’accent sur les tableaux et objets.

## Objectifs

* Manipuler des tableaux avec `map`, `filter`, `reduce`
* Travailler avec des objets et leurs propriétés
* Utiliser le destructuring et le spread operator
* Écrire du code fonctionnel et lisible

## Concepts clés

* `map`, `filter`, `reduce`
* Immutabilité
* Destructuring (arrays / objects)
* Spread / Rest operators
* Méthodes d’objets (`Object.keys`, `Object.values`, `Object.entries`)

## Technologies

* JavaScript (ES6)
* Node.js

## Exécution

```bash
node nom_du_fichier.js
```

## Bonnes pratiques

* Favoriser les fonctions pures
* Éviter les mutations directes
* Utiliser des méthodes déclaratives
* Garder un code lisible et modulaire
