# Node.js – Basic

## Description
Projet d’introduction à **Node.js**, permettant d’exécuter du JavaScript côté serveur et de créer des applications backend simples.

## Objectifs
- Comprendre le fonctionnement de Node.js
- Utiliser les modules (`require` / `import`)
- Manipuler le système de fichiers
- Créer un serveur HTTP simple

## Concepts clés
- Runtime JavaScript
- Modules Node.js
- File System (`fs`)
- HTTP Server
- Asynchronous programming

## Technologies
- Node.js
- JavaScript (ES6)

## Exécution
```bash
node nom_du_fichier.js
